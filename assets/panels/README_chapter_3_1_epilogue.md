# פרק 3.1 — סיום הפליפ-פלופ (החלפת תמונות המחסן)

הסצנה של סיום 3.1 (פאנלים 131–134) משתמשת כרגע ב**תמונות זמניות** (העתק של
`panel118c_chapter_2_5_farewell.jpg`). צריך להחליף אותן בשתי התמונות האמיתיות
ששלחת (פון נוימן ליד שולחן העבודה עם הפליפ-פלופ).

## שתי התמונות הדרושות

1. **תמונה A** — פון נוימן עומד זקוף בפתח הדלת ומביט בשולחן.
   בשימוש בפאנלים **131, 133, 134**.
   שם הקובץ: `panel131_chapter_3_1_more_memory.jpg`
2. **תמונה B** — פון נוימן רכון מעל השולחן ומניח כרטיס ליד הפליפ-פלופ.
   בשימוש בפאנל **132** (שקף ללא טקסט).
   שם הקובץ: `panel132_chapter_3_1_place_card.jpg`

## איך להחליף (צעד-אחר-צעד)

מכיוון שאני לא יכול לשמור את התמונות שהדבקת בצ'אט כקבצים, צריך שתעשה זאת:

1. שמור כל תמונה במחשב בפורמט **JPG** בגודל **1448×1086** פיקסלים
   (אותו יחס כמו שאר הפאנלים). אם התמונה בגודל אחר, זה עדיין יעבוד אבל היא
   תימתח מעט.
2. תן להן **בדיוק** את השמות:
   - תמונה A ← `panel131_chapter_3_1_more_memory.jpg`
   - תמונה B ← `panel132_chapter_3_1_place_card.jpg`
3. העלה/העתק את שני הקבצים אל התיקייה `assets/panels/` (שכתוב על הקבצים
   הזמניים הקיימים באותו שם).
4. אין צורך לגעת בקבצי ה-SVG — הם כבר מפנים לשמות ה-JPG האלה.
5. אם שינית משהו נוסף, זכור לעדכן את מספר ה-`?v=` ב-`index.html` (לא חובה
   בשביל החלפת JPG בלבד, כי לתמונות אין `?v=`, אבל רענון קשיח `Ctrl+Shift+R`
   בדפדפן יבטיח שתראה את התמונה החדשה).
