# לייצא בנייה מהלוח כקובץ פתרון (Ctrl+Shift+8)

פריסה טובה נבנית **על הלוח** — גוררים את הכרטיסים עד שהתמונה נקראת. עד עכשיו לא
הייתה דרך להוציא אותה משם: קבצי הפתרונות ב-`assets/solutions/` נכתבים ביד, וצילום
מסך הוא לא קובץ. הקיצור הזה שומר את הבנייה שעל השולחן כקובץ פתרון.

## מה לעשות

```
פתח את המשחק והיכנס למשימה שאתה רוצה (למשל CPU), כך שהבנייה שלך על השולחן.
סדר את הכרטיסים והכבלים בדיוק כמו שאתה רוצה שהפתרון ייראה.
לחץ Ctrl+Shift+8 (שלושתם יחד).
```

תראה הודעה `נשמר CPU.json — N רכיבים, M חיבורים` באמצע המסך,
והדפדפן יוריד קובץ בשם `<שם המשימה>.json` לתיקיית ההורדות שלך
(בכרום: הקובץ מופיע בפס ההורדות בתחתית החלון, או בלחיצה על אייקון החץ ↓
שנמצא בפינה הימנית העליונה של הדפדפן, מימין לשורת הכתובת).

## מה לעשות עם הקובץ

**כדי להתקין אותו כפתרון:** העתק אותו אל `assets/solutions/` בתיקיית הפרויקט
(דרוס את הקובץ הקיים באותו שם), ואז הרץ בטרמינל מתיקיית הפרויקט:

```
node tools/build-solutions.js
```

זה בונה מחדש את `assets/solutions/solutions.js`, שזה מה שהמשחק והעורך טוענים.

**כדי לפתוח אותו בעורך הפתרונות:** פתח את `editor.html`, לחץ על **"טען JSON…"**
שנמצא בסרגל הכלים למעלה, ובחר את הקובץ שהורד.

## מה נלקח מהלוח ומה לא

מהלוח נלקחים רק הדברים שהלוח באמת מחזיק: **המיקומים, הרכיבים והחיבורים**.
המסגרת, הפינים שלה וה-`check` נלקחים מקובץ הפתרון **הקיים** של אותה משימה — אלה
דברים שנכתבים ביד ולא נבנים על הלוח. הקואורדינטות מוזזות בחזרה ממרחב המשחק
למרחב הקובץ (הפוך מההזזה ש-`workspaceFromSolutionDoc` עושה כשהיא מניחה פתרון).

רכיב שיושב **בתוך** המסגרת נכתב ל-`components`; רכיב שמחוץ לה (מקור המתח שעל
השולחן) נכתב ל-`external`.

הייצוא הוא הלוך-ושוב מדויק: לייצא פתרון קיים בלי לגעת בו מחזיר את אותו קובץ,
אותם מיקומים ואותם חיבורים בדיוק.
