# דחיפה לראשי (main) — הפרסום עצמו

הפיתוח יושב על `claude/github-project-editing-bw3mcp`. הענף `main` הוא מה שהאתר
מגיש, והוא **היסטוריה נפרדת לגמרי** — אין לו אב משותף עם ענף הפיתוח. לכן פרסום
אינו merge ואינו pull request: כל שחרור הוא קומיט אחד על `main` שהעץ שלו זהה
לעץ של ענף הפיתוח, בדיוק כמו כל הקומיטים הקודמים שנקראים
"Publish the current tested build to main".

הכנת הבילד (הפיכת קצב ברירת המחדל ל"צעד אחר צעד", וידוא שכל מסלול לא־גמור אומר
"המשך יבוא...", בדיקות, העלאת מספרי `?v=`, וסנכרון שני ענפי הפיתוח לאותו קומיט)
נעשית בסשן לפני זה. המסמך הזה הוא רק הצעד האחרון — הפרסום.

## 2. ההוראות

הפרסום נעשה מהעותק המקומי שלך, מהטרמינל — לא מהאתר של GitHub. הלינק למעלה הוא
רק כדי לוודא אחר כך שהקומיט החדש באמת הגיע.

פתח טרמינל והיכנס לתיקיית הפרויקט (`cd <התיקייה שבה שמור TheOneMachine>`).

הדבק את הבלוק שבסעיף 3 בבת אחת ולחץ Enter.

לבסוף תודפס שורה אחת שמתחילה ב-`Publish the current tested build to main` — זה
הקומיט החדש על `main`, ואחריה שורת `To https://github.com/...` שמאשרת שהוא נדחף.

אחר כך פתח את הלינק שבסעיף 1; הקומיט העליון ברשימה צריך להיות זה שהרגע נוצר.

לסיום, כדי לוודא שמה ששוחרר הוא באמת מה שהדפדפן מציג, עבור לפי
`docs/RELEASE_CHECK.md` — שקפים (`assets/panels/*.svg`) נשמרים במטמון הדפדפן
ולא מתרעננים לבד.

**שים לב:** הבלוק מוחק שינויים מקומיים שלא נדחפו. אם כתבת משהו בעצמך בעותק
המקומי, הרץ קודם `git status --short` והעתק את הקבצים לתיקייה מחוץ לפרויקט.

## 3. הטקסט להדבקה

```bash
git fetch origin claude/github-project-editing-bw3mcp main && \
git checkout -B main origin/main && \
git read-tree -u --reset origin/claude/github-project-editing-bw3mcp && \
git commit -m "Publish the current tested build to main" && \
git push origin main && \
git checkout claude/github-project-editing-bw3mcp && \
git log --oneline -1 main
```

## איך זה עובד

`git read-tree -u --reset <ענף>` מציב את העץ של ענף הפיתוח באינדקס ובתיקיית
העבודה, בלי להזיז את ה-HEAD שנשאר על `main`. הקומיט שנוצר אחריו הוא קומיט רגיל
על `main` שהעץ שלו זהה בדיוק לענף הפיתוח — כולל קבצים שנמחקו, מה ש-
`git checkout <ענף> -- .` לבדו לא היה עושה.

השורה האחרונה מחזירה אותך לענף הפיתוח, כדי שהעותק המקומי לא יישאר על `main`.
